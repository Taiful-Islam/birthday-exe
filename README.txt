# Birthday.exe 🎂

A CSE-style interactive birthday surprise website.

## Open in VS Code
1. Extract the ZIP.
2. Open the `birthday_exe` folder in VS Code.
3. Open `index.html` with Live Server (recommended) or directly in a browser.

## Before sharing
1. Replace the photos inside `assets/` if needed.
2. Deploy the folder to GitHub Pages or Vercel.
3. Open the website and go to **Create My QR Code**.
4. Paste the live website URL and generate the QR.
5. Print/save the QR and give it to your friend.

Note: The QR generator uses a small QRCode.js library from CDN, so QR generation needs internet access.
